# Semana 04 – GitFlow, Versionamento e Colaboração Profissional

Esta pasta contém a atividade da Semana 04 da disciplina de Técnicas de Hyperautomation, com foco no uso de Git, GitHub e GitFlow no desenvolvimento colaborativo do Portal Fake.

## Objetivo da Atividade

Simular o desenvolvimento colaborativo do Portal Fake utilizando controle de versão com Git, organização de branches com GitFlow e integração de código por meio do GitHub.

## Módulos Desenvolvidos

* `cadastro.py` – módulo de cadastro de usuários;
* `consulta.py` – módulo de consulta de usuários;
* `exportacao.py` – módulo de exportação de dados;
* Gestão, integração e qualidade – validação do fluxo e relatório final.

## Fluxo GitFlow Utilizado

O projeto seguiu o seguinte fluxo:

1. Criação da branch `develop`;
2. Criação das branches `feature`;
3. Desenvolvimento dos módulos;
4. Commit das alterações;
5. Push para o GitHub;
6. Abertura de Pull Request;
7. Revisão e aprovação;
8. Merge na branch `develop`;
9. Merge final na branch `main`.
